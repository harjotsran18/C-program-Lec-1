# C Program - Lec 1

Semester II - C Programming practice exercises and lecture examples.

## Programs

- **`first.c`**: Basic arithmetic and standard I/O in C
- **`age.c`**: Input and display age
- **`bookprice.c`**: Input and display book price
- **`city.c`**: Input and display city name
- **`rollnumber.c`**: Input and display roll number
- **`salary.c`**: Input and display salary
- **`studentname.c`**: Input and display student name
- **`temp.c`**: Input and display temperature

## How to Compile and Run

Using MinGW / GCC:

```bash
gcc filename.c -o filename.exe
./filename.exe
```
